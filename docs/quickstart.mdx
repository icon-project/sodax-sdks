Prefer HTTP? Same flow over REST: [Swap API](/developers/http-api/swaps). Prefer Solana-first? [Solana quickstart](/solana/quickstart).

<Steps>
  <Step title="Install">
    ```bash
    npm install @sodax/sdk
    ```

    You also need a wallet provider for the source chain (e.g. from [`@sodax/wallet-sdk-core`](/developers/packages/connection/wallet-sdk-core)).
  </Step>

  <Step title="Initialize">
    ```typescript
    import { Sodax } from '@sodax/sdk';

    const sodax = new Sodax(); // mainnet defaults
    const init = await sodax.initialize();
    if (!init.ok) {
      console.warn('Using packaged config', init.error);
    }
    ```
  </Step>

  <Step title="Quote and execute">
    ```typescript
    import { ChainKeys } from '@sodax/sdk';

    // Absolute hub deadline (seconds). Prefer getSwapDeadline; 0n = no deadline.
    const deadlineResult = await sodax.swaps.getSwapDeadline(300n); // +5 minutes
    if (!deadlineResult.ok) {
      console.error(deadlineResult.error);
      return;
    }

    const result = await sodax.swaps.swap({
      params: {
        inputToken: '0x…',          // src token
        outputToken: '0x…',         // dst token
        inputAmount: 1_000_000n,
        minOutputAmount: 900_000n,
        deadline: deadlineResult.value,
        srcChainKey: ChainKeys.BSC_MAINNET,
        dstChainKey: ChainKeys.ARBITRUM_MAINNET,
        srcAddress: await evmWalletProvider.getWalletAddress(),
        dstAddress: '0x…',
      },
      walletProvider: evmWalletProvider,
    });

    if (!result.ok) {
      console.error(result.error.code, result.error);
      return;
    }
    ```

    Always branch on `result.ok` / `error.code` — never `try/catch` on the message string.
  </Step>

  <Step title="Poll until settled">
    Use `sodax.swaps.getStatus` until the intent is `SOLVED`, `FAILED`, or `NOT_FOUND`. Full polling sample: [How to make a swap](/developers/packages/sdk/docs/HOW_TO_MAKE_A_SWAP).

    Watch destination fills via `fill_tx_hash` from `getStatus`, or track cross-network message delivery on [SODAX Scan](https://sodaxscan.com).
  </Step>
</Steps>
