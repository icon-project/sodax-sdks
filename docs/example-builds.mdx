_Seven real applications built solo on the SODAX execution and liquidity system, cross-network execution, in production, with live links._

SODAX is infrastructure for modern money: it lets value move, lend, trade, and settle across blockchain networks as if there were no boundaries. This page collects seven things one person built on top of that infrastructure, each shipped, each live, each proving a different surface of the SDK. Across the protocol today that is 21 networks, 25 partner integrations, and 27 money-market assets, and everything below was built against those same public rails.

The through-line: in every build, the cross-network execution was the easy part. The heavy lifting was always somewhere else, a points ledger, a queue state machine, canvas physics, native UI. That is the point of good infrastructure.
