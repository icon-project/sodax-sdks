Build cross-network DeFi with one SDK — swap, lend, borrow, stake, bridge and migrate value across EVM **and** non-EVM chains (Sui, Solana, Stellar, ICON, Injective, NEAR, Stacks and Bitcoin).

<CodeGroup>
```bash Install
pnpm add @sodax/sdk
```

```typescript Initialize
import { Sodax } from '@sodax/sdk';

const sodax = new Sodax();

// optional: fetch the latest chains & tokens from the backend
await sodax.initialize();
```
</CodeGroup>

## Get started in 2 steps

<Steps>
  <Step title="Install the SDK">
    ```bash
    pnpm add @sodax/sdk
    ```
  </Step>
  <Step title="Create a client">
    ```typescript
    import { Sodax } from '@sodax/sdk';

    const sodax = new Sodax();
    ```

    Then follow the [quickstart](/get-started/first-swap) to make your first cross-chain swap.
  </Step>
</Steps>
